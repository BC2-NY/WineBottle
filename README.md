# WineBottle — ワインセラー在庫・棚卸管理

ワインバーの在庫と棚卸を、Google スプレッドシート＋ウェブ入力フォームで管理するツールです。
スマホやPCのブラウザから入力すると、在庫表と棚卸表が自動で組み上がります。

## 構成

| ファイル | 役割 |
|---|---|
| [`Code.gs`](Code.gs) | Google Apps Script 本体。シートの生成・整形・集計・書き戻し・自動再計算 |
| [`index.html`](index.html) | ウェブ入力フォーム（GAS のウェブアプリとして公開） |
| [`セットアップ手順.md`](セットアップ手順.md) | 導入手順と設定変更 |
| [`操作マニュアル.md`](操作マニュアル.md) | 使い方ガイド（初心者向け）。新規登録・在庫修正・棚卸の手順 |

## シート構成

| シート | 内容 |
|---|---|
| **在庫データ** | 生データ。1行＝1アイテム。新規ボトルはここに直接入力（棚・カテゴリはプルダウン） |
| **Cave在庫表** | 棚×ジャンルごとに区分けした在庫リスト。価格帯ごとにグレーの区切り行と小計、ブロック末尾に Total |
| **棚卸表** | 月次棚卸。La Cave 側は自動集計、L'occas 側は手入力 |
| **銘柄DB** | 登録済み銘柄の一覧 |

## 主な機能

- **入力順に依存しない並べ替え** — どの順番で登録しても、棚×ジャンルのブロックに振り分けられ、価格帯の昇順に整列します
- **双方向編集** — `Cave在庫表` を直接書き換えると `在庫データ` へ書き戻されます。新規ボトルは `在庫データ` に直接足せます
- **自動再計算** — 価格帯・小売値・仕入れ値・在庫数を手入力すると、最後の編集から約10秒後に全シートを作り直します（連続編集はまとめて1回）
- **小計・Total は数式** — 在庫数を書き換えた瞬間に追従します
- **入力補助** — 過去に入力したエリア・生産者・Cuvée・品種を候補表示します

## 棚の区分

| 棚 | 区分 | ジャンル |
|---|---|---|
| A棚 | 小売可 | Champagne / ペティヤン / 白 / オレンジ / ロゼ / 赤 |
| B棚 | 日本ワイン・販売可 | 白 / オレンジ / 赤 |
| C棚 | 店内用 | Champagne / ペティヤン / 白 / オレンジ / ロゼ / 赤、JULIワイン、日本ワイン、食後酒 |

棚やジャンルを増やす場合は `Code.gs` の `SHELVES` と `SECTIONS` を編集してください。

## セットアップ

[セットアップ手順.md](セットアップ手順.md) を参照してください。使い方は [操作マニュアル.md](操作マニュアル.md) にまとめています。おおまかな流れは次のとおりです。

1. 新しい Google スプレッドシートを作成
2. 「拡張機能」→「Apps Script」で `Code.gs` と `index.html`（HTMLファイル名は `index`）を貼り付け
3. 関数 `setup` を実行（シート生成＋トリガー設置）
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で公開

## 設定値

`Code.gs` の冒頭で変更できます。

| 定数 | 既定値 | 内容 |
|---|---|---|
| `TAX_RATE` | `0.10` | 消費税率 |
| `DEBOUNCE_MS` | `10000` | 手入力後、再計算するまでの待ち時間（ミリ秒） |
| `SHELVES` / `SECTIONS` | — | 棚とジャンルの定義 |
| `WATCH_COLS` | 価格帯・小売値・仕入れ値・在庫数 | 自動再計算のきっかけになる列 |
